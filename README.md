# Vault — Xela & Alex

Tento priečinok je určený pre **Obsidian**. Sú tu obyčajné textové (markdown) súbory,
ktoré synchronizuje git medzi serverom, tvojím Macom a telefónom.

- `trading/` — dokumenty o obchodovaní, backtesty, plán, manuály (píše Xela)
- `journal/` — tvoj vlastný denník (píšeš ty, Xela ti doň nesiahne)
- `notes/` — ostatné poznámky

**Čo tu zámerne NIE je:** interné súbory asistenta (AGENTS.md, USER.md, MEMORY.md),
skripty a exporty, ani žiadne prístupové údaje či heslá. Tie zostávajú mimo gitu.
